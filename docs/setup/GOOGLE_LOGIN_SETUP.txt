GOOGLE LOGIN SETUP - BELA ARENA

Kod za Google prijavu je dodan u:
- app/login/page.tsx
- app/registracija/page.tsx
- app/auth/callback/page.tsx

Da radi online, u Supabase moraš uključiti Google provider:
1. Supabase -> Authentication -> Providers -> Google -> Enable
2. Upiši Google Client ID i Client Secret
3. U Google Cloud Console u Authorized redirect URI dodaj:
   https://TVOJ-SUPABASE-PROJEKT.supabase.co/auth/v1/callback
4. U Supabase -> Authentication -> URL Configuration dodaj Site URL:
   http://localhost:3000 za lokalno
   ili tvoju Vercel domenu za produkciju

Kod ne mijenja postojeću email prijavu, samo dodaje Google gumb.
